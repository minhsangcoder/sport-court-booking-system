# SportHub frontend

Đây là prototype v0 được giữ nguyên về UI trong Phase 0. Stack hiện tại: Next.js App Router, TypeScript, Tailwind CSS và shadcn/ui.

Dữ liệu và tương tác hiện tại chủ yếu là mock. Không xem các màn hình demo là business implementation hoàn chỉnh. API integration sau này phải dùng client sinh từ `contracts/openapi`.
